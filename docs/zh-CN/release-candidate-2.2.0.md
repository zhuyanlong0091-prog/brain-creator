# Brain Creator 2.2.0 发布候选

本页记录 2.2.0 候选版本的 L3 宿主模式评估边界，不是正式发布公告。

## 已测量内容

源码工作区提供 `npm run verify:l3-eval`。该命令使用确定性的脱敏黄金样本，覆盖：

- HR 业务规则和审批流程。
- 订单审批、驳回和财务交接。
- 图片生成的流程与状态机覆盖。
- 跨角色流程和 AuthProfile 映射。
- 同系统多需求对账。
- 结构化执行证据。
- 20 轮合成 Runner 稳定性样本。

命令会逐项报告 `measured` 或 `not-measured`、样本数量和阈值。需要 JSON 输出时运行 `npm run verify:l3-eval:json`；需要保存到指定路径时直接运行 `node --loader ts-node/esm scripts/l3Eval.ts --json --output <path>`。

## 发布边界

在部署环境提供真实系统回归证据和经过复核的历史 Bug 回放样本之前，报告会保持阻断。合成样本只能证明控制逻辑已接通且结果确定，不能证明任意业务正确性或生产稳定性。

可以使用 `npm run verify:l3-eval:strict` 作为发布门禁。不要提交生成的报告、凭据、浏览器状态、截图、trace 或目标系统数据。

## 后续要求

1. 在明确配置的测试系统上执行已批准的 L3 流程。
2. 导入脱敏历史 Bug 样本并记录回放结果。
3. 使用 `EvaluationTrial` 将外部证据与本基线进行对比。
4. 真实系统门禁通过后，再准备包版本发布。
