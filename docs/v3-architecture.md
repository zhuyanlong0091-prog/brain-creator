# Brain Creator v3 架构

## 一句话定义

Brain Creator 是一个**多模型测试 Agent 框架**。它不绑定任何单一 LLM，而是根据任务类型、复杂度和成本，策略路由到不同模型的 subagent。

---

## Subagent 模型分配

| Subagent | 触发条件 | 模型 | 选择理由 |
|---|---|---|---|
| **Router** | 每次用户输入 | DeepSeek V4 | 分类任务，轻量即可 |
| **Planner** | 新需求 / 新系统接入 | GPT-5.5 | 需要强推理 + 结构化输出 |
| **Generator** | 计划已批准 | GPT-5.5 | 代码生成需精准度 |
| **Healer** | 测试失败 | DeepSeek V4 | 模式匹配为主，成本敏感 |
| **Reviewer** | 执行完成 / 用户要求复盘 | DeepSeek V4 | 文本总结，不需要顶级推理 |

**无需 LLM 的路径（代码状态机直接执行）：**
- 运行已批准的测试链
- 查询资产状态
- 重试计数判断
- Gap 创建/解决
- 密钥加密/脱敏

## 用户感知对比

| | v2 (当前) | v3 |
|---|---|---|
| 用户说的 | "用 Brain Creator 接入这个系统，先添加术语，再生成计划..." | "Brain Creator，接入这个系统，帮我生成并维护测试" |
| 用户需要知道的 | Skill、MCP、40+ 工具名、Planner/Generator/Healer | 无 |
| 流程推进 | 用户手动推进每一步 | Brain Creator 自主推进 |
| 模型 | 单一（Claude 子进程） | 多模型，按任务路由 |
| 成本 | 所有推理走强模型 | 轻活走轻模型，重活走强模型 |

## 与 LangChain/LangGraph 的分工

```
LangGraph 提供:                    Brain Creator 自己写:
─────────────────                  ─────────────────
· StateGraph 状态机                · 系统上下文 (鉴权/术语/规则)
· 节点路由和条件分支                · 测试链流程 (Planner→Generator→Healer)
· 多模型绑定                       · Gap 系统
· Checkpoint 持久化                · 资产索引和查询
· 工具绑定                         · 密钥安全边界
· 流式输出                        · 测试领域 Quality Gate
· 人机交互中断 (Human-in-the-loop)  · Spec ↔ 结构化用例互转
                                   · Playwright Seed 生成
```
