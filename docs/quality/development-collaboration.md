## 设计决策

| 决策 | 原因 | 验收方式 |
| --- | --- | --- |
| Trial 显式绑定新 Suite | 同系统旧结果不能冒充本轮测量 | 历史 Suite 不允许挂入新 Trial；跨系统和跨需求拒绝 |
| 固定选定场景作为分母 | 避免剔除 blocked/未执行后美化完成率 | 重试不增加场景数，未运行仍在分母 |
| 真实与合成测量分开 | 夹具通过不能证明真实业务能力 | synthetic/unknown 不计入真实成功分子 |
| 缺少人工介入追踪时显示未测量 | 没有记录不等于没有人工介入 | 不生成无依据的自主率和零干预结论 |
| 流程边歧义不得选第一条 | 共享来源不能证明动作相同 | 多边/多模型反例；唯一确认路径正例 |
| 实现与验收分离 | 降低实现者同时认定自己正确的风险 | 审查 diff、失败反例、独立运行测试和记录残余风险 |
